## IntelliSense 误报修复（"无法引用已删除的函数"）
- 现象：编辑器在 `this->Channel = channel;` 处报 `std::__1::basic_string::operator=` 为已删除函数，但真实编译通过。
- 根因：llvm-mingw 用 libc++（`std::__1`），cpptools 的 EDG 引擎在 windows-gcc-x64 模式下解析 libc++ 头文件产生误报（已知问题）。
- 修复：安装 clangd 扩展（市场源无此扩展，从 open-vsx 下载 VSIX 安装，publisher 是 `llvm-vs-code-extensions`），`.vscode/settings.json` 配置 `clangd.path` 指向 llvm-mingw 自带 clangd.exe、`--compile-commands-dir=build`，并设 `C_Cpp.intelliSenseEngine: disabled`。
- 验证：`clangd --check=Src/Pub_Sub.cpp` 输出 0 errors
