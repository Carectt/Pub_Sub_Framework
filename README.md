# Pub_Sub_Framework

一个用于学习 C++17 发布订阅模式的小项目。当前实现以频道登记发布者和订阅者，并在订阅者的工作线程中接收 `std::any` 消息。`Src/main.cpp` 用 IMU 向 `Pitch` 频道发送整数，供 PID 示例订阅。

项目仍在实验阶段，接口和行为可能变化，适合阅读与试验，暂不适合生产环境或实时控制系统。

## 构建

需要 C++17 编译器、CMake 3.10 或更高版本，以及线程支持。

```sh
cmake -S . -B build
cmake --build build
```

运行 `build` 目录下的 `Pub_Sub_Framework`（Windows 上为 `Pub_Sub_Framework.exe`）。示例会持续发送并打印消息，没有自动退出条件；结束时请中断进程。构建系统默认选择 Debug。

## 代码导航

- `Inc/Pub_Sub.hpp`、`Src/Pub_Sub.cpp`：发布者、订阅者及频道注册表。
- `Inc/Msg.hpp`：消息序号与泛型载荷。
- `Src/main.cpp`：最小使用示例。
- `tests/`：独立的收发检查及高频发送探针，运行方式见 [测试说明](tests/README.md)。
- [开发记录](DevLog.md)：实现过程中的历史笔记；其中的“当前状态”指记录当时的状态。

## 已知限制

- 订阅者只设一个临时消息槽；高频发送时可能丢失消息，不保证每条都送达。
- 订阅者使用分离线程，目前没有安全的停止、注销和析构流程；示例依赖进程结束清理。
- 频道注册表和投递操作尚未建立完整的并发保护，多线程使用需要谨慎。
- `Get_Value<T>()` 要求载荷类型与 `T` 一致，否则会抛出 `std::bad_any_cast`。
- `Broker` 目前只是预留模块。
